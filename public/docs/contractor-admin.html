협력사 관리

협력사명·연락처·공종·MSDS를 관리합니다. 사업자등록증 작업과 개별 링크 관리 버튼은 이 목록에서 제거했습니다.

사업자등록증 — 미제출 협력사

사업자등록증 탭은 미제출 목록을 기본으로 엽니다. 협력사명을 검색하고 해당 업체의 등록증을 바로 업로드할 수 있습니다.

사업자등록증 — 제출 완료

제출 완료로 전환하면 파일 보기·삭제가 표시됩니다. 전체 다운로드는 협력사명으로 저장한 등록증 ZIP을 내려받습니다.
