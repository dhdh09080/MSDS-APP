🤖 AI 분석 API 🔒 사용자별 암호화 저장
개인 API를 하나만 등록하면 그 API를 사용하고, 여러 개를 등록하면 문서 유형에 가장 알맞은 한 곳만 자동 선택합니다. API 사용료는 각 제공자 계정에 직접 청구되며, 키 원문은 저장 후 다시 표시되지 않습니다.
보안 기본값공개 협력사 링크는 AI를 호출하지 않습니다. 로그인한 사용자가 분석을 실행할 때만 자동 선택된 제공자 한 곳으로 문서가 전송되며, 문서·프롬프트 원문은 이 시스템의 사용량 기록에 저장하지 않습니다.
분석 경로 확인 중등록된 API에 따라 자동 선택 규칙을 표시합니다.

처음 사용하시나요? API 키 발급·복사·입력 방법
  1. 아래에서 사용할 AI 제공자의 공식 API 키 페이지를 엽니다.
  2. 로그인 후 결제수단 또는 크레딧을 등록하고 새 Secret/API key 만들기를 누릅니다.
  3. 생성 직후 한 번만 표시되는 키를 복사합니다. 키를 메신저나 문서에 공유하지 마세요.
  4. 위 입력칸에 붙여넣고 저장을 누릅니다. 하나만 등록하면 그 API를, 여러 개면 분석 종류에 맞는 API 한 곳을 자동 사용합니다.
