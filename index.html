🤖 AI 분석 API 🔒 사용자별 암호화 저장
개인 API를 하나만 등록하면 그 API를 사용하고, 여러 개를 등록하면 문서 유형에 가장 알맞은 한 곳만 자동 선택합니다. API 사용료는 각 제공자 계정에 직접 청구되며, 키 원문은 저장 후 다시 표시되지 않습니다.
보안 기본값 공개 협력사 링크는 AI를 호출하지 않습니다. 로그인한 사용자가 분석을 실행할 때만 자동 선택된 제공자 한 곳으로 문서가 전송되며, 문서·프롬프트 원문은 이 시스템의 사용량 기록에 저장하지 않습니다.
분석 경로 확인 중 등록된 API에 따라 자동 선택 규칙을 표시합니다.

초대 링크 만들기
링크를 복사해 초대할 팀원에게 직접 전달하세요. 상대방이 로그인하거나 회원가입한 뒤 가입을 신청하고, 담당자의 승인을 받으면 현장에 합류합니다. 링크는 7일간 유효하며 한 명만 사용할 수 있습니다.

링크를 가진 사람이 가입을 신청할 수 있으며 담당자 승인 후 참여합니다. 초대할 팀원에게만 전달하세요. 이 창을 떠나면 링크 원문은 다시 표시되지 않습니다.
